# JointsGH



Fixed, Hinge y Spring Joints hechos en una misma escena.



* Puente para el Fixed funcional con 80 de Break Force y de Break Torque. Al caer la bola el puente se derrumba.



* En Hinge la puerta se abre hasta 90 grados y empuja la bola.



* En Spring la bola hace el efecto de una bola Bungee, con un Damper de 1.5 para que tenga rebote pero no se pase.
